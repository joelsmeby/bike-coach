# Archived material

This folder preserves old work. It is not the source directory for a new change or device upload.

- `firmware/BikeCoach_Artemis_v0_2_6/`: original tracked historical firmware, retained from GitHub without changing its source.
- `web/`: earlier `app.js` and `app-v3.js` implementations. The current webpage uses `app-v4.js` in the project root. These files are historical reference; their old relative imports are not a runnable archived website.
- `local/2026-10-18/packages/`: previous downloaded release ZIPs on this Mac.
- `local/2026-10-18/sketch-copies/`: extracted sketch folders and the locally modified historical v0.2.6 experiment.
- `local/2026-10-18/INVENTORY.json`: original locations, new locations, sizes and SHA-256 fingerprints of the moved local files. File contents were checked before and after the moves.

`local/` is excluded from Git. The original workspace backup is also retained under `.local/backups/`; neither is an off-machine backup. Published candidate packages belong in GitHub Releases, and current source belongs in the Git checkout.

Older installation notes are under `docs/history/`. Backlog and validation status belong in Notion.
