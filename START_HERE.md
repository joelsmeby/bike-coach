# Start here

Use [README.md](README.md) for the official source paths, checks and working process.

Download clearly labeled installation packages from [GitHub Releases](https://github.com/joelsmeby/bike-coach/releases). A candidate release has automated-check evidence; it is not a claim of physical bike/phone validation.

For firmware development and upload from this checkout, use `firmware/OpenLog_Artemis_BikeCoach/OpenLog_Artemis_BikeCoach.ino`. The other sketch copies have been archived.

The backlog and project status live in the [current Notion hub](https://app.notion.com/p/3efee7b8cda381faa796c34ea717c6b7).

Earlier installation notes are preserved in [release history](docs/history/RELEASE_NOTES_THROUGH_0_2_11.md). They describe earlier points in time and should not be treated as current instructions.
